# Pesquisa — Conecta gov.br (catálogo de APIs do governo)

- **Data:** 15/10/2026
- **Fonte:** [Catálogo de APIs do Conecta gov.br](https://www.gov.br/conecta/catalogo/apis)
- **Conclusão:** **não serve à plataforma.** O Conecta é a interoperabilidade entre órgãos públicos (federais, estaduais e municipais); os consumidores são órgãos do governo, não empresas privadas.

| API no Conecta | Para a plataforma |
| --- | --- |
| Consulta CNPJ (dados cadastrais) | Existe versão comercial na loja da Serpro; também há dados abertos da Receita. Útil para preencher o cadastro pelo CNPJ (depois do MVP) |
| CND federal e Consulta Dívida Ativa da União | Úteis para certidões automáticas (depois do MVP); procurar via comercial oficial |
| Cadin, Hub Cobrança e Gestão de Dívida Ativa | Para órgãos credores; não se aplicam |

Não há no catálogo APIs de FGTS (CRF), certidão trabalhista, Simples Nacional, MEI, eSocial nem emissão de guias. Tributos federais seguem pelo Integra Contador ([serpro-integra-contador.md](serpro-integra-contador.md)).
